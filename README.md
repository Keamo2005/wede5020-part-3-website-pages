## Project Overview

The **Artisan Delight** is a website developed as part of an assignment in the WEDE subject. This application was created using **Kotlin** and **Visual Studio**.

The app was developed to meet the requirements of the assignment, which includes creating a functional mobile app and utilizing GitHub for version control and CI/CD automation using GitHub Actions.

---

## Overview
Established in 2021, Artisan Delight started as a small, family-owned home bakery committed to sustainable baking practices. Recognizing a growing demand for high-quality, responsibly sourced food, the business transitioned into a commercial storefront and micro-bakery in 2023. By building direct supply lines with local farms, they created a resilient operation capable of rapidly adjusting production volume without sacrificing quality.

### Key Features:
- Feature 1: Create a my own website
- Feature 2: Use of semantic HTML5 elements
- Feature 3: Focused on HTML structure and correct use of HTML tags

### Goals
- Showcase daily menus, small-batch specials, and active seasonal baked goods.
-	Establish an online pre-ordering channel for local catering and event orders.
-	Educate consumers about local farm partnerships and eco-friendly baking practices.

### Timeline & Milestones
Weeks 1 – 2: Planning and content - This includes developing the site map, determining the placement of high-resolution images of the baked goods, and defining the navigation system.
Weeks 3 – 4: Wireframing and design - The website will be sketched out and designed using a recycled colour scheme and a user-friendly product display system.
Weeks 5 – 8: Front-end development - This will involve building the website’s HTML structure, designing it with CSS to evoke the desired aesthetics, and adding interactivity with JavaScript.
Weeks 9 – 10: Testing and deployment - The website will be tested for responsiveness to different screen sizes, and the contact form will be reviewed. The website will also be deployed to the domain and made live.
